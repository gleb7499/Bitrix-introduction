# Сайты, сгенерированные ИИ по макетам

Навигация по работам:

- Figma to code → [демо](https://gleb7499.github.io/Bitrix-introduction/Figma-to-code/)
- Anima + Claude Sonnet 4.5 → [демо](https://gleb7499.github.io/Bitrix-introduction/Anima+Claude-Sonnet-4.5/)

## Результат

- **Figma to code** - внешне результат выглядит намного лучше чем работа Anima + Claude Sonnet 4.5, с более точным соответствием макету, но структура кода настолько отвратительная, что дальше модифицировать его практически невозможно.
- **Anima + Claude Sonnet 4.5** - результат далек от идеала внешне, но структура сделана нормально, и его можно доработать вручную.

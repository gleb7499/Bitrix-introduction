## 🚀 Основные особенности

### ✅ Соответствие стандартам (AGENT.md)

- **Семантический HTML5**: использование `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- **Доступность (a11y)**: ARIA-атрибуты, управление клавиатурой, видимый фокус
- **Mobile-First**: адаптивная верстка с базовыми стилями для мобильных
- **BEM-подобный нейминг**: префикс `.pg-` (page) для изоляции стилей
- **CSS Variables**: централизованное управление цветами, отступами, шрифтами
- **Производительность**: ленивая загрузка изображений, оптимизированные стили

### 📱 Адаптивность

Три брейкпоинта:
- **Mobile**: ≤ 767px (базовые стили)
- **Tablet**: 768px - 1023px
- **Desktop**: ≥ 1024px

## 🛠️ Установка и запуск

### Вариант 1: Простой запуск

Просто откройте `index.html` в браузере. Сайт работает без серверной части.

### Вариант 2: Локальный сервер (рекомендуется)

Используйте любой локальный веб-сервер:

**С помощью Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**С помощью Node.js (http-server):**
```bash
npx http-server -p 8000
```

**С помощью VS Code:**
Установите расширение "Live Server" и нажмите "Go Live".

Затем откройте: `http://localhost:8000`

## 📝 Что нужно добавить

### 1. Изображения

Добавьте изображения в папку `assets/img/`:

```
assets/img/
├── logo-invers.png            # Логотип (35x40px)
├── hero-main.png              # Главное изображение (1076x720px desktop)
├── about-illustration.png     # Иллюстрация о компании
├── stage-1.png до stage-4.png # Этапы внедрения
├── advantage-1.png до advantage-4.png # Преимущества
├── avatar-1.png, avatar-2.png # Аватары для отзывов
├── seo-illustration.png       # SEO блок
├── client-1.svg до client-5.svg # Логотипы клиентов
└── service-1.png до service-4.png # Иллюстрации услуг
```

**Рекомендации по изображениям:**
- Используйте WebP для фотографий (с PNG fallback)
- SVG для логотипов и иконок
- Оптимизируйте размер (TinyPNG, Squoosh)
- Используйте `srcset` для адаптивных изображений

### 2. Шрифты

Шрифт Inter подключен через Google Fonts. Для лучшей производительности можно:

1. Скачать шрифты локально
2. Положить в `assets/fonts/`
3. Подключить через `@font-face` в `globals.css`

### 3. Модальные окна

В JavaScript есть заглушки для модальных окон. Нужно реализовать:

- Форму обратной связи
- Форму заказа консультации
- Форму оставить заявку
- Валидацию полей
- Отправку данных на сервер

Пример в `assets/js/main.js` (строка ~140):

```javascript
// TODO: Implement actual modal with form
function openModal(modalType) {
  // Создать overlay
  // Создать модальное окно
  // Добавить форму
  // Обработать отправку
}
```

### 4. Интеграция с Bitrix

Для интеграции с CMS 1С-Битрикс:

1. Переместите `index.html` в шаблон: `local/templates/bitrix_intro/`
2. Разделите на `header.php`, `footer.php`, компоненты
3. Подключите стили и скрипты через `$APPLICATION->SetAdditionalCSS()`
4. Используйте компоненты Битрикс для форм, меню и т.д.

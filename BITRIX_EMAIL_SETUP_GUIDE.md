# 📧 Инструкция по настройке отправки форм в Bitrix

## 🎯 Что мы настраиваем

После того, как вы загрузили все файлы на хостинг, нужно настроить почтовую систему Bitrix, чтобы при отправке форм письма приходили на **<sales@intezgroup.ru>**.

---

## 📋 Пошаговая инструкция для 5-летнего ребёнка 😊

### ШАГ 1: Заходим в админку Bitrix

1. Откройте ваш сайт в браузере
2. Добавьте к адресу `/bitrix/admin/` (например: `https://ваш-сайт.ru/bitrix/admin/`)
3. Введите логин и пароль администратора
4. Вы попали в админ-панель Bitrix! 🎉

---

### ШАГ 2: Настраиваем почтовый ящик для отправки

**Зачем это нужно?** Bitrix должен знать, с какого email-адреса отправлять письма.

1. В левом меню админки найдите раздел **"Настройки"** → **"Настройки продукта"**
2. Откройте вкладку **"Почтовые настройки"** (или "Почта")
3. Найдите поле **"Почтовый адрес отправителя по умолчанию"**
4. Введите: `noreply@intezgroup.ru` (или любой другой email от вашего домена)
5. Нажмите **"Сохранить"**

**💡 Совет:** Если у вас есть SMTP-сервер (например, от mail.ru, yandex.ru или вашего хостинга), можно настроить его здесь же для надёжной отправки.

---

### ШАГ 3: Создаём тип почтового события

**Зачем это нужно?** Это шаблон события, которое будет срабатывать при отправке формы.

1. В левом меню админки найдите раздел **"Настройки"** → **"Почтовые события"** → **"Типы событий"**
   - Полный путь: `Настройки` → `Настройки продукта` → `Почтовые события` → `Типы событий`

2. Нажмите кнопку **"Добавить тип события"** (обычно в правом верхнем углу)

3. Заполните форму:

   - **ID типа события:** `FEEDBACK_FORM` (латиницей, без пробелов!)
   - **Название:** `Форма обратной связи`
   - **Описание:** `Событие срабатывает при отправке формы на сайте`
   - **Сортировка:** `100`

4. Ниже будет секция **"Шаблон для сайта"** (или "Описание параметров"):

   Добавьте следующие параметры (это переменные, которые будут доступны в шаблоне письма):

   ```
   #NAME# - Имя клиента
   #PHONE# - Телефон клиента
   #PAGE_URL# - URL страницы, с которой отправлена форма
   #SERVICE_NAME# - Название услуги (определяется автоматически)
   #DATE_TIME# - Дата и время отправки
   ```

   Просто скопируйте и вставьте этот текст в поле "Описание параметров"

5. Нажмите **"Сохранить"**

---

### ШАГ 4: Создаём шаблон почтового сообщения

**Зачем это нужно?** Это содержимое письма, которое придёт на почту менеджеру.

1. В левом меню админки найдите раздел **"Настройки"** → **"Почтовые события"** → **"Почтовые шаблоны"**
   - Полный путь: `Настройки` → `Настройки продукта` → `Почтовые события` → `Почтовые шаблоны`

2. Нажмите кнопку **"Добавить шаблон"**

3. Заполните форму:

   **Блок "Основное":**
   - **Активность:** ✅ Поставьте галочку "Активен"
   - **Тип события:** Выберите из выпадающего списка `FEEDBACK_FORM` (тот, что создали в Шаге 3)
   - **От кого (email):** `noreply@intezgroup.ru` (или ваш email)
   - **От кого (имя):** `IntezGroup Сайт`
   - **Кому (email):** `sales@intezgroup.ru` ⚠️ **ЭТО ВАЖНО!** Сюда будут приходить все заявки
   - **Копия (CC):** Можно оставить пустым (или добавить дополнительные email через запятую)
   - **Тема письма:**

     ```
     Новая заявка с сайта: #SERVICE_NAME#
     ```

4. **Блок "Тело письма" (HTML-формат):**

   Скопируйте и вставьте этот HTML-код:

   ```html
   <!DOCTYPE html>
   <html>
   <head>
       <meta charset="UTF-8">
       <title>Новая заявка</title>
   </head>
   <body style="font-family: Arial, sans-serif; line-height: 1.6; color: #333;">
       <div style="max-width: 600px; margin: 0 auto; padding: 20px; border: 1px solid #ddd; border-radius: 8px;">
           <h2 style="color: #2c5aa0; margin-top: 0;">📧 Новая заявка с сайта</h2>
           
           <table style="width: 100%; border-collapse: collapse; margin: 20px 0;">
               <tr>
                   <td style="padding: 10px; background: #f5f5f5; font-weight: bold; width: 200px;">👤 Имя клиента:</td>
                   <td style="padding: 10px; background: #fff;">#NAME#</td>
               </tr>
               <tr>
                   <td style="padding: 10px; background: #f5f5f5; font-weight: bold;">📞 Телефон:</td>
                   <td style="padding: 10px; background: #fff;"><a href="tel:#PHONE#" style="color: #2c5aa0; text-decoration: none;">#PHONE#</a></td>
               </tr>
               <tr>
                   <td style="padding: 10px; background: #f5f5f5; font-weight: bold;">🎯 Интересующая услуга:</td>
                   <td style="padding: 10px; background: #fff;">#SERVICE_NAME#</td>
               </tr>
               <tr>
                   <td style="padding: 10px; background: #f5f5f5; font-weight: bold;">🔗 Страница сайта:</td>
                   <td style="padding: 10px; background: #fff;"><a href="#PAGE_URL#" style="color: #2c5aa0;">#PAGE_URL#</a></td>
               </tr>
               <tr>
                   <td style="padding: 10px; background: #f5f5f5; font-weight: bold;">⏰ Дата и время:</td>
                   <td style="padding: 10px; background: #fff;">#DATE_TIME#</td>
               </tr>
           </table>
           
           <div style="margin-top: 30px; padding: 15px; background: #e8f4fd; border-left: 4px solid #2c5aa0;">
               <p style="margin: 0;"><strong>💡 Рекомендация:</strong> Свяжитесь с клиентом в течение 15 минут для максимальной конверсии!</p>
           </div>
           
           <hr style="margin: 30px 0; border: none; border-top: 1px solid #ddd;">
           
           <p style="font-size: 12px; color: #999; text-align: center; margin: 0;">
               Это автоматическое уведомление с сайта IntezGroup.ru<br>
               Отвечать на это письмо не нужно
           </p>
       </div>
   </body>
   </html>
   ```

5. **Блок "Тело письма" (Текстовый формат):**

   Скопируйте и вставьте этот текст (для почтовых клиентов, не поддерживающих HTML):

   ```
   ========================================
   НОВАЯ ЗАЯВКА С САЙТА
   ========================================

   Имя клиента: #NAME#
   Телефон: #PHONE#
   Интересующая услуга: #SERVICE_NAME#
   Страница сайта: #PAGE_URL#
   Дата и время: #DATE_TIME#

   ========================================
   Рекомендация: Свяжитесь с клиентом в течение 15 минут!
   ========================================

   Это автоматическое уведомление с сайта IntezGroup.ru
   ```

6. Нажмите **"Сохранить"**

---

### ШАГ 5: Проверяем, что всё работает

1. Зайдите на ваш сайт (не в админку!)
2. Найдите любую форму (например, "Получить ответ за 15 минут" в конце главной страницы)
3. Заполните форму своими тестовыми данными:
   - Имя: `Тест`
   - Телефон: `+7 999 999 99 99`
4. Нажмите **"Отправить"**
5. Должно появиться сообщение "Спасибо! Ваш запрос принят..."
6. Проверьте почту **<sales@intezgroup.ru>** — туда должно прийти письмо с вашими данными!

## 🔧 Дополнительные настройки (необязательно, но полезно)

### Настройка SMTP для надёжной отправки

Если письма не приходят или попадают в спам, настройте SMTP:

1. Зайдите в **"Настройки"** → **"Настройки продукта"** → **"Почтовые настройки"**
2. Установите галочку **"Использовать SMTP для отправки писем"**
3. Заполните данные SMTP-сервера (их выдаёт ваш хостинг или почтовый провайдер):
   - **SMTP-сервер:** например, `smtp.yandex.ru` или `smtp.mail.ru`
   - **Порт:** `465` (SSL) или `587` (TLS)
   - **Логин:** ваш email (например, `noreply@intezgroup.ru`)
   - **Пароль:** пароль от этого email
   - **Шифрование:** выберите `SSL` или `TLS`
4. Нажмите **"Сохранить"** и **"Проверить соединение"**

---

### Как изменить email получателя

Если нужно, чтобы письма приходили на другой адрес:

1. Зайдите в **"Настройки"** → **"Почтовые события"** → **"Почтовые шаблоны"**
2. Найдите шаблон `FEEDBACK_FORM` (он будет один в списке)
3. Нажмите на него для редактирования
4. Измените поле **"Кому (email)"** на новый адрес
5. Сохраните

## 🐛 Что делать, если письма не приходят

### Проблема 1: Письма вообще не отправляются

**Решение:**

1. Зайдите в **"Настройки"** → **"Журналы"** → **"Почтовые события"**
2. Посмотрите, есть ли там записи о попытках отправки
3. Если записей нет — проверьте, что тип события `FEEDBACK_FORM` создан правильно
4. Если записи есть, но с ошибками — читайте текст ошибки

### Проблема 2: Письма попадают в спам

**Решение:**

1. Настройте SMTP (инструкция выше)
2. Проверьте SPF/DKIM записи вашего домена (спросите у хостинга)
3. Используйте email-адрес отправителя с вашим доменом (например, `noreply@intezgroup.ru`, а не `gmail.com`)

### Проблема 3: В письме не подставляются данные (#NAME# вместо имени)

**Решение:**

1. Проверьте, что в PHP-файле `/local/ajax/send_form.php` правильно заполняется массив `$arEventFields`
2. Проверьте, что имена переменных в шаблоне совпадают с именами в массиве (например, `#NAME#` в шаблоне и `'NAME'` в PHP)

## 📞 Техническая поддержка

Если что-то не получается:

1. **Проверьте логи Bitrix:**
   - `Настройки` → `Журналы` → `Почтовые события`
   - Там будут все попытки отправки и ошибки

2. **Проверьте файл на сервере:**
   - Убедитесь, что файл `/local/ajax/send_form.php` загружен на хостинг
   - Откройте его в браузере: `https://ваш-сайт.ru/local/ajax/send_form.php`
   - Должна быть ошибка 405 "Метод не поддерживается" (это нормально, значит файл работает)

3. **Свяжитесь с техподдержкой хостинга** — возможно, у них заблокирована отправка почты через PHP

# 🎯 Инструкция по внедрению динамических страниц услуг в 1С-Битрикс

## 📋 Общая концепция

Вы создаёте **инфоблок** (базу данных услуг) в админке Битрикса, где добавляете услуги как отдельные элементы. Когда пользователь переходит по ссылке `/services/bitrix24/implementation/`, компонент Битрикса автоматически подтягивает нужную услугу из базы и отображает её в вашем HTML-шаблоне.

---

## 🏗️ Шаг 1: Создание инфоблока для услуг

### 1.1. Создаём тип инфоблока

1. Зайдите в **Контент → Инфоблоки → Типы инфоблоков**
2. Нажмите **"Добавить тип инфоблока"**
3. Заполните:
   - **ID**: `services`
   - **Название**: `Услуги`
   - **Разделы**: ☑ Да
   - **RSS**: ☐ Нет
   - **Язык**: русский
4. Сохраните

---

### 1.2. Создаём инфоблок

1. Зайдите в **Контент → Инфоблоки → Управление инфоблоками**
2. Нажмите **"Добавить инфоблок"**
3. Заполните:
   - **Тип инфоблока**: `Услуги (services)`
   - **Название**: `Каталог услуг`
   - **Символьный код**: `service-catalog`
   - **Активность**: ☑ Да
   - **Сортировка**: `500`

4. **Вкладка "Поля"**:
   - ☑ Название элемента (`NAME`)
   - ☑ Детальное описание (`DETAIL_TEXT`) — **включить визуальный редактор**
   - ☑ Детальная картинка (`DETAIL_PICTURE`)
   - ☑ Анонсное описание (`PREVIEW_TEXT`)
   - ☑ Анонсная картинка (`PREVIEW_PICTURE`)

5. Сохраните инфоблок (запомните его **ID**, например, `1`)

---

## 🎨 **Как создать свойство в админке (пошагово)**

1. Зайдите в **Контент → Инфоблоки → Каталог услуг**
2. Нажмите кнопку **"Свойства"**
3. Нажмите **"Добавить свойство"**
4. Заполните:
   - **Название**: например, "Заголовок Hero"
   - **Код**: например, `HERO_TITLE`
   - **Тип**: выберите из списка (Строка/Текст/Файл/Список)
   - **Множественное**: ☑ если нужно несколько значений (например, для списков)
   - **Обязательное**: ☑ если поле должно быть заполнено
5. Сохраните

Повторите для всех 16 свойств из таблицы выше.

## 🔗 Шаг 4: Настройка ЧПУ (человекопонятных URL)

### 4.1. Создаём файл `.section.php` для раздела услуг

Создайте файл `/services/.section.php`:

```php
<?php
$sSectionName = "Услуги";
$arDirProperties = Array(
   "description" => "Услуги компании - 1С, Битрикс 24, ИТ-инфраструктура",
   "keywords" => "услуги, 1с, битрикс24, ит-инфраструктура"
);
?>
```

### 4.2. Создаём файл для детальной страницы

Уже создан в: `/local/services/bitrix24/implementation/index.php`

**Важно!** В файле `index.php` укажите правильный **ID инфоблока** (параметр `IBLOCK_ID`), который вы узнали после создания инфоблока (обычно `1`).

## 🚀 Шаг 5: Копирование файлов на сервер

Скопируйте созданные файлы из папки `local/` в **корень вашего Битрикс-сайта**:

```
/local/templates/main/...              → /local/templates/main/...
/local/services/bitrix24/...           → /services/bitrix24/...
/local/services/1c/...                 → /services/1c/...
```

**⚠️ Внимание!** Структура должна быть такой:

```
/
├── bitrix/
├── local/
│   └── templates/
│       └── main/
│           ├── header.php
│           ├── footer.php
│           └── components/
│               └── bitrix/
│                   └── news.detail/
│                       └── service_detail/
│                           └── template.php
├── services/
│   ├── bitrix24/
│   │   └── implementation/
│   │       └── index.php
│   └── 1c/
│       └── support/
│           └── index.php
└── index.php
```

## ✅ Итоговая схема работы

```
Пользователь кликает "Внедрение Битрикс 24"
           ↓
Открывается URL: /services/bitrix24/implementation/
           ↓
Битрикс запускает index.php в этой папке
           ↓
index.php вызывает компонент bitrix:news.detail
           ↓
Компонент ищет элемент с кодом "bitrix24-implementation"
           ↓
Компонент загружает шаблон template.php
           ↓
template.php выводит HTML с данными из $arResult
           ↓
Пользователь видит красивую страницу!
```

## 🛠️ Частые проблемы

### Проблема: Страница 404

**Решение:** Проверьте, что:

- Файл `index.php` существует по нужному пути
- В админке существует элемент с нужным `ELEMENT_CODE`
- В компоненте правильно указан `IBLOCK_ID`

### Проблема: Отображается пустая страница

**Решение:**

- Проверьте логи PHP на ошибки
- Убедитесь, что у элемента заполнены обязательные поля
- Проверьте права доступа к инфоблоку

### Проблема: Не подтягиваются картинки

**Решение:**

- Убедитесь, что свойства типа "Файл" созданы правильно
- Проверьте, что в элементе загружены картинки
- Проверьте код: `CFile::GetPath($arResult['PROPERTIES']['...']['VALUE'])`

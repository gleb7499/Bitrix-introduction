## 📝 Описание

Современный адаптивный шаблон сайта для IT-компании с полной интеграцией в Bitrix24/1С-Битрикс. Включает:

- ✅ Полностью адаптивный дизайн (desktop, tablet, mobile)
- ✅ Интеграция с компонентами Bitrix (меню, формы, новости)
- ✅ Модальные окна и формы обратной связи
- ✅ Интерактивные элементы (карусели, аккордеоны, выпадающие меню)
- ✅ Оптимизация под SEO
- ✅ Lazy loading для изображений
- ✅ Готовые секции для всех страниц сайта

## 🚀 Установка

### Шаг 1: Загрузка файлов

Скопируйте папку `local` в корень вашего сайта Bitrix:

```
/bitrix/
/local/          ← Сюда
/upload/
index.php
```

**Важно:** Если у вас уже есть папка `local`, скопируйте только содержимое `local/templates/main` в `local/templates/main`.

### Шаг 2: Установка шаблона через админ-панель

1. Войдите в административную панель Bitrix
2. Перейдите: **Настройки → Настройки продукта → Сайты**
3. Выберите ваш сайт
4. В поле "Шаблон по умолчанию" выберите **IntezGroup - Main Template**
5. Нажмите **Сохранить**

### Шаг 3: Очистка кеша

После установки обязательно очистите кеш:

1. **Настройки → Производительность → Управление кешем**
2. Нажмите **Очистить весь кеш**

## ⚙️ Настройка

### Меню сайта

Для корректной работы меню создайте типы меню в админ-панели:

1. **Настройки → Настройки продукта → Настройки модулей → Главный модуль → Типы меню**
2. Добавьте тип меню `top` с названием "Верхнее меню"

Создайте меню:

1. **Контент → Структура сайта → Меню**
2. Выберите тип меню: **top**
3. Добавьте пункты меню согласно структуре сайта

**Пример структуры меню:**

```
- О компании (с подменю)
  - О компании
  - Вакансии
  - Отзывы
  - FAQ
  - Акции и скидки
- Цены
- Проекты
- Блог
- Контакты
```

### Формы обратной связи

Шаблон использует компонент `bitrix:form.result.new` для форм.

**Создание веб-формы:**

1. **Сервисы → Веб-формы**
2. Создайте форму "Обратный звонок" (ID: 1)
3. Добавьте поля:
   - Имя (text)
   - Телефон (text)
4. В настройках формы укажите:
   - Email для уведомлений
   - Текст успешной отправки

**Примечание:** ID формы в шаблоне указан как `1`. Если у вас другой ID, измените в `header.php`:

```php
"WEB_FORM_ID" => "1", // Замените на ваш ID
```

### Настройка путей к изображениям

Все пути к изображениям в шаблоне используют константу `SITE_TEMPLATE_PATH`, которая автоматически формирует правильные пути. Никаких дополнительных настроек не требуется.

## 🧩 Компоненты

### Используемые компоненты Bitrix

1. **bitrix:menu** - Меню сайта
   - Шаблон: `top_menu`
   - Расположение: `header.php`

2. **bitrix:form.result.new** - Формы обратной связи
   - Шаблон: `callback_modal` (создайте при необходимости)
   - Расположение: `header.php` (модальное окно)

### Создание собственных шаблонов компонентов

Для создания кастомного шаблона компонента:

1. Создайте папку: `local/templates/main/components/bitrix/[component_name]/[template_name]/`
2. Скопируйте файлы из оригинального компонента
3. Адаптируйте под дизайн

**Пример для формы обратной связи:**

```
local/templates/main/components/bitrix/form.result.new/callback_modal/
├── template.php
├── style.css
└── script.js
```

## 📞 Поддержка

### Часто задаваемые вопросы

**Q: Как изменить логотип?**
A: Замените файлы в папках:

- Desktop: `local/templates/main/images/icons/logo-header-desktop.svg`
- Mobile: `local/templates/main/images/icons/logo-header-mobile.svg`

**Q: Как изменить номер телефона?**
A: Измените в файлах `header.php` и `footer.php`:

```php
<a href="tel:+74954765464" class="header__phone">+7 495 476-54-64</a>
```

**Q: Как добавить новую секцию на главную страницу?**
A:

1. Создайте файл секции в корне сайта или используйте включаемые области
2. Используйте компоненты Bitrix или статичный HTML
3. Подключите через `$APPLICATION->IncludeComponent()` или `$APPLICATION->IncludeFile()`

**Q: Меню не работает корректно**
A: Проверьте:

1. Создан ли тип меню `top`
2. Заполнено ли меню в админке
3. Очищен ли кеш

**Q: Формы не отправляются**
A: Проверьте:

1. Создана ли веб-форма с нужным ID
2. Корректно ли указан ID в `header.php`
3. Настроены ли Email для уведомлений
